# 格 Cardgrid

极简卡片网格探针主题：一屏一格的服务器卡片，留白为骨、发丝为线。

纯白底、1px 发丝线、无 emoji 国旗、无 Web 字体。数据用等宽字体，正文用系统
字体栈。配色与圆角是固定的：这个主题只有一种样子，`theme.json` 里的设置项的
作用都是决定显示哪些内容，不是换肤。

## 安装

从 release 下载 `theme.tar.gz`，在 hub 面板里安装；或让 hub 直接从
本仓库的 release 读取。包里只有普通文件和目录，包根就是主题目录。

## 开发

需要 Node 22 以上。

> 本仓库没有提交 lockfile（依赖是照参考主题的版本手装的）。首次 `pnpm install`
> 会按 `package.json` 的 semver 范围解析，装出来的版本可能与本机验证过的略有差异。
> CI 里的 `typecheck` 与 `build` 是判据。

```sh
pnpm install
pnpm dev            # 开发服务器，/api 代理到 MONITOR_HUB 或 127.0.0.1:9911
pnpm typecheck      # tsc -b
pnpm build          # tsc -b && vite build && node scripts/build-theme.mjs
pnpm preview:shot   # 对着运行中的预览服务器重新生成 preview.png
pnpm pack           # 打 theme.tar.gz
```

没有真实 hub 时，用 `node scripts/mock-hub.mjs 9911` 起一个假 hub，
它按真实响应的形状返回数据，含在线、待上报、上报异常、离线四种状态。

## 设计约束

这几条是刻意的，改动前请先读 `CONSTRAINTS.md`：

- **整页一个 measure**。`.masthead`/`.summary`/`.tabs`/`.grid` 都读 `--measure`，
  不许各带各的 `max-width`——页头 1600px、栅格 1180px 时标题就比它命名的卡片
  靠左 130px。
- **卡片五行固定，不随视口变**。CPU/内存/存储/上传/下载 是 `repeat(5, minmax(0,1fr))`，
  不是 `auto-fill`：五行是内容本身，网格自己决定列数会在卡片窄几个像素时把它们
  折成两行，同一屏的卡片高度立刻参差。
- **一列里的标签、数值、进度条居中对齐**。五条等宽轨道如果各自左对齐，`0.5%` 和
  `84.30%` 右边留下的空隙不一样，一整行读起来是五个各自起头的散列。居中之后每个
  标签压在自己数字的正上方。进度条是例外，它占满整条轨道——长度本身就是读数。
- **总上传 / 总下载是两个等分格**，不是两列。它们是同一个数的两个方向，各占一列
  会让它们看起来像 CPU 那样两个独立的读数。
- **一个圆角**。`--radius` 一个变量管卡片、面板、图表、按钮。曾经有过圆角设置项，
  结果卡片和它里面的面板可以不一致，而圆角是读者在读任何东西之前就看见的东西。
- **汇总四格用 `grid-auto-rows: 1fr`**。网络/费用格有两行副标题，计数格没有；
  不给等高的话四个框高度不齐，手机 2×2 时第二行比第一行高。
- **分组用 `null` 表示「全部」**，不用字符串。分组名是站长任意填的，可能就叫
  `全部` 或 `*`，用字符串当哨兵会让那个分组点不开。
- **汇总跟着分组走**。切了分组，上方四个数字按这一组算，不一半跟分组一半跟全站。
- **同 URL 的并发请求合并**。详情页三张图会同时请求同一个窗口，hub 对历史构建
  有并发上限，撞上会返回 503，而图表会把 503 读成「没有数据」。
- **不要给系列画面积**。面积以轴底为基线，而这几个图的轴底是 0、用量只是总量
  的一小部分，每一张都会渲染成一块灰板。
- **密集时间序列按像素列取最小/最大值**，不逐点连线。探针在七天档上报 721 次、
  图宽约 900px，采样点相距 1.2px，逐点连线会在几乎每个像素处反转方向——那条锯齿
  完全是画法产生的，不携带链路的任何信息。按列折叠成一根跨度线，极值分毫不差：
  尖峰还是同样高的尖峰，消失的只有采样点之间的亚像素抖动。
- **`Chart` 的默认轴顶是 1**，任何图都必须显式给 `top` 或 `domain`，否则数据会落到
  图外几千像素。
- **每个图表的图例状态分开存**。共用一个 `hidden` 集合时，隐藏一个探针会把另一
  张图里同名 id 的系列一起隐藏。
- **采样点超过 100 不留孤立点圆点**。按自身节奏上报的探针几乎每个点都是孤立的，
  密集图上会画出上百个圆点，并把 SVG 组的包围盒撑到几万像素。
- **设置值永不进 `innerHTML`**。markdown 返回 React 节点，链接只放行
  `http:`/`https:`/`mailto:`。
- **站点设置只放 hub**，不放 localStorage；访客偏好才可以放 localStorage。
- **设置项必须有人读**。`theme.json` 声明了一个键，就得有代码读它——一个没人读
  的键在面板里看起来是个开关，扳动它什么也不会发生。`columns`、`show_remark`、
  `show_latency`、`radius`、`accent`、`font`、`density` 七个键就是这样被删掉的。
  注意 `hairline`/`hover_lift` 是发布成 `data-*` 属性由 CSS 选择器消费的，用
  「有没有带引号的键名」去审计会误报。
- **没换算成功就别假装换算过**。多币种且没选显示币种时，两个数字单位不同，
  副标题写「各自计价」，不能写「N 种币种」——那读起来像已经合并算了。

## 预览图

`preview.png` 是真实截图，不是示意图。对着运行中的预览服务器跑：

```sh
PREVIEW_W=1300 PREVIEW_H=1100 PREVIEW_KEEP=1 node scripts/preview.mjs http://127.0.0.1:4321/
```

`PREVIEW_KEEP=1` 保留原始尺寸便于查看，不加则缩到面板要的 960x600。
